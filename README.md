# VYOMAKE - Cosmic Ideas. Engineered Reality.

![VYOMAKE Logo](/public/logo.png)

A futuristic, animated, and highly technical website for VYOMAKE – an AI solutions company building real-world engineered AI systems.

## 🚀 Live Demo

[View Live Website](https://ddl2gsyhds6wc.ok.kimi.link)

## ✨ Features

### Interactive Hero Section
- 3D particle background with Three.js
- Interactive orbs that follow mouse movement
- Scroll-based ring speed animation
- Floating interactive elements with hover effects
- Mouse-responsive 3D tilt on content

### Customer Logos Section
- Partner company showcase with pulsing ring borders
- Animated project count displays
- Hover reveal with success stats
- Total projects counter with glow animation

### Services Section
- 4 main service cards with 3D tilt effects
- 4 additional service tiles with animated icons
- Unique icon animations for each service
- Glassmorphism design with hover glow effects

### Live Dashboard Mockup
- Real-time updating charts (Area, Bar, Pie)
- System performance meters
- Live data simulation
- Interactive UI elements

### Additional Sections
- IoT Manufacturing Automation showcase
- Office & Home Automation solutions
- Contact form with animated states
- Responsive navigation with smooth scroll

## 🛠️ Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **3D Graphics:** Three.js / React Three Fiber
- **Charts:** Recharts
- **UI Components:** shadcn/ui

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/vyomake-website.git

# Navigate to project directory
cd vyomake-website

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
